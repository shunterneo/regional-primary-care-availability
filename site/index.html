How updates work: Every published record includes its last research review date and a public evidence link. The scheduled source monitor checks for changes in public pages and sends discrepancies to a review queue. Unambiguous clinic-specific official statements confirmed on two separate days can update the map and documents automatically. Conflicting findings remain queued for review. Officially listed government program sites may appear with intake unconfirmed; permanent closures require explicit first-party evidence.

Privacy: This page contains public clinic information only. It makes no analytics, tracking, geocoding, or third-party API requests. Links to clinic websites open only when selected. This is not a certified PHIPA-compliant patient-record system, and it must not receive client details.
