## UI implication
All ten support ongoing-care pathways; none is included merely because a walk-in appointment is possible. Some offer both service types. This does not create a useful ongoing-versus-walk-in distinction among an attachment-only list: the meaningful user choices are intake evidence/status, eligibility, geography, wait, and registration route. Walk-in offerings may remain secondary card information, not a competing attachment search mode.
