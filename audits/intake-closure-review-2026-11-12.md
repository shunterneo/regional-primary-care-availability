## Safeguard change

Negative display now requires recent organization-owned evidence, a recorded finding, matching source attribution and no unresolved conflict. Third-party-only, missing, mismatched or over-21-day-old negative evidence becomes Needs reconfirmation. Refreshing the record date alone cannot refresh evidence. Forbes Park's existing conflict consequently displays Needs reconfirmation with both statements retained.

This symmetry reduces unsupported negative claims; it does not make webpage statements equivalent to direct operational confirmation. Regression tests cover third-party negatives, conflicting reports, mismatched hosts, missing findings and stale evidence dates. Validation, build, evidence tests and JavaScript smoke tests passed locally; GitHub runs the full suite before deployment.
